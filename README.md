# Zooming and Panning Options with Blazor Charts

This sample demonstrates how to implement zooming and panning functionality using **Syncfusion Blazor Charts**. The project focuses on configuring interactive chart behaviors that allow users to explore data efficiently by zooming into specific regions and navigating between zoomed areas using panning options.

The application includes examples of enabling various zooming modes, customizing the chart toolbar, and automatically managing axis intervals while zooming. These capabilities help improve data visualization and usability when working with large or detailed datasets in Blazor applications.

## Project Overview

This project serves as a reference implementation for developers who want to add interactive zoom and pan behavior to charts built with Syncfusion Blazor components. It illustrates how chart navigation can be enhanced without modifying underlying data by relying on built-in chart configuration options.

The sample is intended for educational and demonstration purposes and aligns closely with Syncfusion’s official charting guidelines and APIs.

## Features

- Enable zooming on chart axes for detailed data inspection  
- Support panning to move across zoomed chart areas  
- Configure zooming modes and toolbar options  
- Automatically adjust axis intervals during zoom operations  
- Demonstrate interactive chart navigation using Blazor  

## Prerequisites

To run this project, ensure the following requirements are met:

- Visual Studio 2022 installed on your system  
- Basic knowledge of Blazor and C#  
- Access to required NuGet packages used by the solution  

## How to Run the Project

1. Clone or download this repository to a local directory.
2. Open the solution file using **Visual Studio 2022**.
3. Restore all NuGet packages by rebuilding the solution.
4. Run the project to view the chart zooming and panning functionality in action.

## Usage

Once the application is running, interact with the chart using mouse or touch input to zoom into specific data regions. Use the available toolbar controls to reset zoom or switch between navigation modes.
